# Campus Calendar — Learnistan Techspace

A front-end Campus Calendar prototype styled to match the supplied designs and logo for Learnistan Techspace. The separate marketing/landing page has been removed; opening `index.html` takes you directly to the calendar interface.

## Open the website
1. Extract the ZIP file.
2. Open `index.html` in a modern browser, or open the folder in VS Code and use Live Server.
3. Use the sign-in and create-account links to explore the authentication screens.

## Included screens
- Calendar interface (entry screen)
- Sign in, create account, forgot password, and reset password
- Dashboard, calendar, events, saved events, and create event
- Event details, profile, notifications, settings, help and support
- Admin dashboard

## Current scope
This delivery is front-end only, as requested. There is no backend or database. Any demo interactions or browser storage are local to the browser and are not real multi-user authentication, email delivery, or shared synchronization. Do not enter real passwords or sensitive personal data.


## Branding update
Designed for Learnistan Techspace with a refined navy-blue dashboard, consistent blue interaction states, improved logo presentation, and responsive front-end styling. This package remains front-end only; no backend has been added.
